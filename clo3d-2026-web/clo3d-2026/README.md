# CLO 3D 2026 · Fabricación Digital

Web del módulo CLO 3D: guías de cada clase, práctica paso a paso, glosario bilingüe y referencia Windows/macOS.

- `index.html`: toda la web (HTML, CSS y JS en un solo archivo). Carga las fuentes desde Google Fonts.
- `img/`: capturas de CLO (`c01_*` Clase 01, `c02_e01_*` y `c02_e02_*` Clase 02).

Para verla, abre `index.html` en el navegador o publica la carpeta (por ejemplo con GitHub Pages).

Para agregar una clase, edita el arreglo `CLASES` al inicio del `<script>`; el glosario está en `GLOSARIO`.
